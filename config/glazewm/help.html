GlazeWM shortcuts

Alt + H / J / K / L focuses windows; Alt + 1–9 switches workspaces. Alt + M minimizes; Alt + Q closes. All work in every mode while management is active.

NormalCommandMoveAdjustAdmin

Normal

Active by default

Key Action
Alt + H / J / K / L Focus left / down / up / right.
Alt + 1–9 Switch workspace.
Alt + Shift + ; Enter Command.

Command

Activate: Alt + Shift + ;

Key Action
M Enter Move.
R Enter Adjust.
A Enter Admin.
H Open this guide in the default browser; exit Command.

Escape, Enter or Alt + Shift + ; → Normal.

Move

Activate: Alt + Shift + ; → M

Key Action
H / J / K / L Move left / down / up / right.
Shift + H / J / K / L Move the workspace to the display left / down / up / right.
V Switch the focused tile’s split between side-by-side and above/below.
1–9 Move to workspace and follow the window; stay in Move.

V prepares where new or moved windows join the tile. It may have no visible effect until another window joins; it does not rotate an existing group.

Escape or Enter → Normal. Alt + Shift + ; → Command.

Adjust

Activate: Alt + Shift + ; → R

Key Action
H / L Decrease / increase width by 2%.
J / K Decrease / increase height by 2%.
T Set tiled.
F Toggle fullscreen.
Space Toggle floating; center when floating.
M Minimize.

Escape or Enter → Normal. Alt + Shift + ; → Command.

Admin

Activate: Alt + Shift + ; → A

Key Action
R Reload configuration; exit Admin.
P Pause / resume management; stay in Admin.

While paused, press P to resume before using other controls.

Escape or Enter → Normal. Alt + Shift + ; → Command.
